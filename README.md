# Цифровой двойник реактора: Мониторинг концентрации реагента B (Вариант 15)

## 1. Назначение программы
Программа представляет собой цифровой двойник технологического процесса, моделирующий мониторинг концентрации реагента B (в %) на основе данных, поступающих от виртуального датчика. 
Программа выполняет потоковую обработку данных: считывает показания (в текущей версии — генерирует их для демонстрации), преобразует их в индикатор состояния процесса (Q), выполняет оперативный контроль (проверку границ) и определяет текущее состояние технологического процесса.

## 2. Алгоритм работы программы
Программа реализует следующий алгоритм (соответствует схеме оперативного контроля):
1. **Инициализация:** Задание параметров контроля (верхняя граница `UCL`, нижняя граница `LCL`, диапазон `X`).
2. **Потоковый цикл (N = 70 измерений):**
   - Получение текущего значения датчика `X` (концентрация, %).
   - Преобразование `X` в индикатор `Q` по кусочно-заданной функции.
   - Сравнение `Q` с границами контроля `UCL` и `LCL`.
   - Отображение состояния (`НОРМА` / `ПРЕДУПРЕЖДЕНИЕ`).
   - Сохранение `X` и `Q` в массивы для последующего анализа.
3. **Аналитический этап:** Расчет статистических характеристик (среднее, медиана) по заданному интервалу накопленного массива `Q`.

## 3. Организация данных
В программе используются следующие основные структуры данных:

| Данные | Назначение | Структура |
| :--- | :--- | :--- |
| `X` | Текущее показание датчика (концентрация реагента B, %) | Переменная типа `double` |
| `Q` | Текущее значение индикатора процесса (большая точность) | Переменная типа `double` |
| `X[]` | Накопленная телеметрия исходных показаний | Статический массив `double` размером `N` |
| `Q[]` | Накопленная телеметрия индикаторов процесса | Статический массив `double` размером `N` |

## 4. Математическая модель и пример расчета
Преобразование показания `X` в индикатор `Q` осуществляется по кусочно-заданной функции (в соответствии с Вариантом 15):

*   Если `X < 30`:  `Q = 3 * (X - 30) + 10`
*   Если `30 ≤ X ≤ 55`: `Q = 2 * √(X - 42.5 + 12) + 45`
*   Если `X > 55`: `Q = (X - 55)² / 6 + 55`

**Примеры ручного расчета:**
1.  **X = 25.0** (меньше 30)
    `Q = 3 * (25 - 30) + 10 = 3 * (-5) + 10 = -15 + 10 = -5`
2.  **X = 42.5** (в диапазоне 30–55)
    `Q = 2 * √(42.5 - 30.5) + 45 = 2 * √12 + 45 ≈ 2 * 3.464 + 45 = 51.928`
3.  **X = 61.0** (больше 55)
    `Q = (61 - 55)² / 6 + 55 = 36 / 6 + 55 = 6 + 55 = 61`

*Примечание: В программе реализован контрольный пример для X = 52.50, который должен дать Q ≈ 54.38.*

## 5. Алгоритм контроля и его результаты
Для контроля используется базовая проверка границ (Уровень 1 — базовый).
Нормальный режим работы: `30 ≤ X ≤ 55 %`. 
Верхняя граница индикатора `Q`: `UCL = 61.93`. 
Нижняя граница индикатора `Q`: `LCL` (в данной реализации принята равной `Q` при `X=30`, т.е. `10.0`).

| Условие | Состояние | Действие программы |
| :--- | :--- | :--- |
| `LCL ≤ Q ≤ UCL` | **NORMAL (НОРМА)** | Продолжение мониторинга |
| `Q > UCL` | **WARNING (ПРЕДУПРЕЖДЕНИЕ)** | Вывод сообщения: "ВНИМАНИЕ! Отклонение" |
| `Q < LCL` | **WARNING (ПРЕДУПРЕЖДЕНИЕ)** | Вывод сообщения: "ВНИМАНИЕ! Отклонение" |

*При обнаружении выхода за границы программа инкрементирует счетчик отклонений и выводит причину перехода в состояние предупреждения.*
